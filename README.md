# Music Genre Classifier

## Project Description
This project predicts the genre of a music file using Machine Learning and audio feature extraction.

## Technologies Used
- Python
- Streamlit
- Librosa
- Pandas
- NumPy
- Scikit-learn

## Features
- Upload a music file
- Predicts the music genre
- Fast and simple interface
